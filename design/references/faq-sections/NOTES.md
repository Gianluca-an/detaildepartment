## Status — Cayenne CHOSEN + BUILT (client sent screenshot 2026-09-16)
Client picked the **Cayenne** layout for the landing-page FAQ.
Layout (from screenshot): **two columns** — LEFT a big bold uppercase heading
("RESPONDEMOS TUS DUDAS.") + a muted subtitle (stays put / sticky); RIGHT an

a thin hairline divider; open answers show in muted gray. Set over a dark,
low-key car photo backdrop.
